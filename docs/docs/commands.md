# Comandos

## /study [minutos]

Inicia el modo estudio. Envía una pregunta inmediatamente y agenda envío automático cada N minutos.

**Uso:**
- `/study` — Usa el intervalo default (30 min)
- `/study 15` — Envía una pregunta cada 15 minutos

## /study_stop

Detiene el modo estudio y cancela los envíos programados.

## /topics

Lista los temas disponibles en el repositorio de preguntas.

## /help

Muestra la lista de comandos disponibles.
